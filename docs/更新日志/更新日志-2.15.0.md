# 缘启 YuanQi Launcher 2.15.0

**版本**：2.15.0 · **发布**：2026-11-17 · **安装包**：`YuanQi-Setup-2.15.0.exe`

## 便携化

- 设置、账户、缓存、日志、临时文件、自动下载的 Java、离线皮肤、联机模块与它的数据全部收进程序目录下的 `YQL` 文件夹。不再写注册表，不再写 `%AppData%`；把 `YQL` 一起拷走就等于带走了全部状态。
- 首次启动自动迁移：注册表里的历史设置搬进 `YQL\Setup.ini`，`%AppData%\YQL` 里的账户与缓存搬进程序目录，旧临时目录一并归位；迁移前留一份 `YQL\RegistryBackup.ini` 备份，迁移完清掉注册表键。
- 自动下载的 Java 装到 `YQL\Runtime`，不再写进官方启动器的 `.minecraft\runtime`；启动器自己下载管理的 Java 在列表里不能移除（移除了下次扫描还会回来）。
- 需要纯 ASCII 路径的 natives 目录、JIT 热点文件、离线自定义皮肤都改到程序目录，不再固定写官方启动器文件夹。
- 自定义事件变量的读写从注册表改成 `YQL\Setup.ini`，与 `{variable:...}` 替换标记读到的是同一份数据。
- 「使用高性能显卡」默认关闭：它是唯一还会写注册表的选项，关于页已注明这一例外。
- 联机模块随程序一起分发，数据存在 `YQL\Terracotta`，不再落到 `%AppData%`。

## 联机

- 中转节点地址修正：默认节点改用 `/node1`（根路径返回空内容，等于一个节点都没有）；节点列表改为从官方 `terracotta.glavo.site/nodes` 实时获取，取不到时退回内置节点。
- 取消逐行写盘：模块输出改为在内存里保留最近 300 行，只在失败时落盘。之前每行都写文件、界面又反复整文件读取，加入房间时会拖到整机卡死。
- 失败时附上模块自己的 `application.log`：模块退出前先把日志复制到数据目录，再清理临时目录，避免还没读到就被删掉。
- 连接中与取消、返回的过渡速度分档：取消和返回立即收起外框，进入仍是完整动画。
- 步骤轨道改为按阶段推进：当前行划线，结束后整块上移一行，下方说明等阶段追上后才换。

## 首页

- 问候语改为按条件抽取的句子池：时段、周末与节假日、账号、版本、游玩数据各自对应不同句子；同一账号同一版本下保持不变，不会每次刷新都在跳。
- 抽句会避开最近用过的几条，记录跨启动生效，不再反复撞到同一句。
- 国庆和春节的问候语用喜庆红色标题。
- 游戏运行中，启动按钮变成「关闭游戏」并换成方块图标，可以直接关掉这次运行；只有同一账号开的同一版本才算，切到别的账号仍可照常多开。
- 点击问候语开启彩蛋：启动按钮开始躲鼠标，进入 150 像素躲开、退回 225 像素才回来；此时点任意按钮随机跳一个页面，背景转为彩色渐变；再点一次关闭。
- 问候语要用到的游玩记录改为后台读取，启动不再为它停顿。

## 账户

- 头像文件改为原子替换，界面不会再读到写了一半的图片。
- 文件暂时读不到或解码失败时隔 160 毫秒重试一次，不再直接掉成默认头像。
- 头像一律显示账户自己的副本，不直接指向会被「刷新皮肤」清掉的共享缓存。

## 游戏统计

- 「最近游玩」按游戏归组：同一个游戏的名字只出现一次，下面缩进列出每次的时间与时长；某游戏次数过多时收成一行「还有 N 次」。

## 窗口

- 修复硬件加速模式下摘边框首次真正生效后窗口无法缩放的问题：缩放热区改由启动器自绘，鼠标进入时有显示，可正常命中，层级在最上层。

## 下载与更新

- 检查更新改为用启动器自己的下载器下载安装包：进度进右下角任务列表，支持镜像源与分段下载，带大小与 sha256 校验；上一次残留的半截文件会先清掉。
- Mod 前置检查改用版本 JSON 里原样带的前置 ID，不再依赖页面加载时那次额外查询，不再出现「有时能查、有时查不到」。

## 设置

- 全站说明文字改写：去掉对举句式与分号堆叠，统一术语与标点，只说结果不说过程。
- 判定「无法移除的 Java」改为识别启动器自己下载管理的 Java，便携版目录同样能识别。
- 关于页的隐私声明更新：数据全部在程序的 `YQL` 文件夹内，唯一例外是主动勾选高性能显卡时写的一条系统显卡首选项。
