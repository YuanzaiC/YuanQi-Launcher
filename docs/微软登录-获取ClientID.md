# 怎么获取微软登录用的客户端 ID

> 缘启启动器的「登录微软账户」需要一个 Azure 应用的**客户端 ID（client_id）**才能工作。
> 这个 ID 不是密钥，公共分发也没关系，但必须是你自己注册的应用——所以第一次用要花几分钟申请一个。

整个过程约 5 分钟，**不需要付费订阅**。你需要：

- 一个能登录的 Microsoft 账号（用来注册应用，可以和你玩游戏的账号分开）；
- 一份正版 Minecraft: Java Edition（登录流程最后会校验游戏资格）。

---

## 第 1 步：打开 Azure 门户

浏览器打开 <https://portal.azure.com>，用 Microsoft 账号登录。

## 第 2 步：注册一个应用

1. 顶部搜索框输入「**应用注册**」，进入 **Microsoft Entra ID → 应用注册**；
2. 点「**新注册**」，只填三项：
   - **名称**：随便起，用户登录时会看到这个名字，例如 `缘启启动器`；
   - **受支持的帐户类型**：选「**仅限个人帐户**」
     （只有这一项能让任意微软个人账号登录；选错会报 `AADSTS50020`）；
   - **重定向 URI**：**留空**（我们用的是设备代码流，不需要）。
3. 点「注册」。

## 第 3 步：复制客户端 ID

注册完会进入应用概览页，复制「**应用程序(客户端) ID**」——一串像
`12345678-1234-1234-1234-1234567890ab` 的字符。这就是要填进启动器的值。

> 目录(租户) ID 用不到，不用管。
> 「证书和密码」里**什么都不要建**：设备代码流不需要客户端密码，建了也别塞进客户端。

## 第 4 步：允许公共客户端流

左侧「**身份验证**」→ 拉到最下面的「高级设置」→ 把「**允许公共客户端流**」选成「**是**」→ 点「保存」。

> 不开这一项，登录时会报 `AADSTS7000218`（要求提供客户端密码）。

## 第 5 步：填进启动器

启动器 →「**设置**」→「**高级**」→ 「微软登录 · 应用客户端 ID」，把刚才那串 ID 粘进去。

- 填完**立刻生效**，不用重启；
- 留空就是「未启用微软登录」；
- 填错只会让微软登录失败，其它功能不受影响。

然后到启动页 →「添加账户」→「**登录微软账户**」：

1. 启动器弹出设备码（形如 `ABCD-EFGH`），并自动复制到剪贴板、打开浏览器；
2. 在浏览器里输入设备码 → 用有正版游戏的微软账号登录 → 同意权限；
3. 回到启动器，会自动拉取账号信息，账户池里标注「正版」即为成功。

## 常见错误

| 报错 | 原因 / 处理 |
| --- | --- |
| `AADSTS900144` 缺少 client_id | 启动器里还没填 ID |
| `AADSTS700016` 找不到应用 | ID 抄错了；或应用注册的账户类型不是「仅限个人帐户」 |
| `AADSTS7000218` 要客户端密码 | 第 4 步的「允许公共客户端流」没开 |
| `AADSTS50020` | 账户类型选成了「仅我的组织」，改成「仅限个人帐户」 |
| `AADSTS65001` | 授权时没点同意，重新登录并同意 |
| `slow_down` / `429` | 设备码请求太频繁，等 1~2 分钟再试 |
| 登录页显示「未验证的应用」 | 只是提示，点「继续」即可 |
| 提示没有 Minecraft 资格 | 这个微软账号没买 Java 版，换号 |

## 安全提醒

- **客户端 ID 可以公开**，它不是密钥；
- 但**不要**在应用注册里创建客户端密码（client secret）并放进启动器，那等于把密码公开；
- 这个应用只申请 `XboxLive.signin` 和 `offline_access` 两个范围，用来登录并读取你的 Minecraft 档案，不会拿到你的密码。
